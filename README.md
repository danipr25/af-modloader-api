# AF Mod Loader API

Shared helpers for **Alchemy Factory** mods loaded by AF Mod Loader, so mods that touch the same parts of the game coexist instead of overwriting each other. It is a regular mod that other mods depend on, and it includes a template for starting new mods.

Status: early development. Not usable yet. The API stays at 0.x, and may change, until 1.0.

Unofficial fan project. Alchemy Factory belongs to its developers.
